📁 Archive Zero 사용 방법

1. 시작하기

  • 앱 시작 시 Google 계정으로 로그인하세요. 재방문 시 자동 로그인됩니다.
  • 로그인 후 프로필 목록이 표시됩니다. 처음이라면 ＋ 새 프로필 만들기로 프로필을 만드세요.
  • 각 프로필에 선택적으로 4자리 PIN을 설정할 수 있습니다 (설정하지 않으면 바로 입장).
  • 다른 기기에서도 같은 Google 계정으로 로그인하면 동일한 프로필과 라이브러리를 볼 수 있습니다.

2. 항목 추가

  • 화면 하단의 탭 메뉴에서 게임 추가 / 영상 추가를 선택하세요. 좌우 스와이프로도 탭을 전환할 수 있습니다.
  • 제목 입력란에 두 글자 이상 입력하면 자동으로 검색됩니다 (게임: RAWG, 영상: TMDB).
  • 검색 결과를 클릭하면 장르·발매일·설명·이미지가 자동으로 채워집니다.
  • 상태와 플랫폼/매체를 고르고 추가를 누르면 라이브러리에 저장됩니다.

3. 라이브러리

  • 상단의 검색창으로 제목·장르·메모를 빠르게 찾을 수 있습니다.
  • 정렬 드롭다운에서 등록순 / 출시일 / 메타스코어 / 알파벳순 정렬을 선택할 수 있습니다.
  • 상태 칩(엔딩·플레이 중·플레이 예정 / 정주행·시청 중·시청 예정)을 눌러 표시할 항목을 토글할 수 있습니다.
  • 오른쪽 ⋯ 메뉴에서 카드/목록 보기 전환, 엑셀 내보내기, Steam 가져오기, 정보 보강을 모두 이용할 수 있습니다.

4. Steam 라이브러리 가져오기

  • Steam에서 보유한 게임 목록을 한 번에 불러올 수 있습니다 (게임 라이브러리 탭의 🎮 Steam 가져오기 버튼).
  • ① steamdb.info/calculator에 접속합니다.
  • ② Sign in via Steam을 눌러 Steam 계정으로 로그인합니다.
  • ③ View your profile을 클릭합니다.
  • ④ 아래로 스크롤해 게임 목록을 드래그한 뒤 엑셀(또는 스프레드시트)에 붙여넣습니다.
  • ⑤ 게임명 열만 남기고 나머지 열은 삭제한 후 CSV(또는 텍스트)로 저장합니다.
  • ⑥ 🎮 Steam 가져오기 버튼으로 저장한 파일을 업로드합니다.
  • ⑦ RAWG에서 장르·발매일·이미지를 자동으로 채워 라이브러리에 추가됩니다. 데모·베타·테스트 항목과 이미 등록된 게임은 자동 제외됩니다.

5. 프로필 관리 (헤더 버튼)

  • ＋ 새 프로필: 새 프로필을 만듭니다. PIN은 선택 사항입니다.
  • ✎: 현재 프로필의 이름을 변경합니다.
  • 🔒: 현재 프로필의 PIN을 설정·변경·해제합니다.
  • 프로필 삭제: 현재 프로필과 모든 데이터를 영구 삭제합니다.
  • 👤: Google 계정에서 로그아웃합니다.
  • 🌙 / ☀️: 다크/라이트 테마를 전환합니다.

6. 동기화

  • Google 계정으로 로그인하면 자신의 데이터만 볼 수 있으며, 다른 사용자의 데이터는 완전히 격리됩니다.
  • 다른 기기에서 같은 Google 계정으로 로그인하면 동일한 프로필과 라이브러리가 보입니다.
  • 항목 추가/수정/삭제 시 잠시 후 자동으로 클라우드에 반영됩니다.
